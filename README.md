# AI 국어 문항 시스템 미리보기

2022 개정 교육과정 국어과 성취기준으로 선택형 문항을 만들고 검수하는 사내 웹 콘솔의 화면 미리보기입니다.

- 보기: https://swansongre-commits.github.io/aikorean-viewer/
- 화면: 문항 은행, 문항 생성, 검수함, 작업 현황, 성취기준, 평가지
- 실제 프로그램의 화면 코드를 **예시 데이터**로 렌더링한 정적 파일입니다. 저장, 생성, 삭제는 되지 않습니다.
- 교과서 지문, 기출 문항, 사내 자료는 들어 있지 않습니다. 성취기준 문장과 해설은 교육과정 자료입니다.
- 글꼴: Noto Sans KR (SIL Open Font License, `FONT-LICENSE.txt`)

본 저장소(비공개)의 `tools/build_viewer.py` 로 다시 만듭니다.
